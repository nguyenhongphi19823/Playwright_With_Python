# Bài 09 — pytest đầu tiên

Đây là bộ file độc lập của riêng bài học này. Hãy chỉnh code trong folder này và giữ nguyên folder của các bài trước để có thể mở lại, chạy lại và so sánh.

## Mục đích

Hiểu quy ước tên file, tên function và cách pytest thu thập test.

## File chính

`tests/test_math.py`

## Cách sử dụng

1. Giải nén file tải từ website.
2. Mở folder `lessons/bai-09-pytest-first-test/` bằng trình soạn thảo code.
3. Mở file `.py`: comment tiếng Việt ngay phía trên giải thích ý nghĩa của từng dòng code.
4. Thực hiện bài tập: Tạo thêm test_subtraction và cố ý cho fail một lần để đọc output.

## Quy tắc của lộ trình

Không sửa tiếp file của bài trước. Mỗi bài là một sandbox riêng để phần thay đổi luôn rõ ràng.
