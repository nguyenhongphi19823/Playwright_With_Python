# Bài 07 — Exception & custom error

Đây là bộ file độc lập của riêng bài học này. Hãy chỉnh code trong folder này và giữ nguyên folder của các bài trước để có thể mở lại, chạy lại và so sánh.

## Mục đích

Biến lỗi nghiệp vụ thành tín hiệu rõ ràng thay vì trả về giá trị mơ hồ.

## File chính

`user_manager.py`

## Cách sử dụng

1. Giải nén file tải từ website.
2. Mở folder `lessons/bai-07-exceptions-and-custom-errors/` bằng trình soạn thảo code.
3. Mở file `.py`: comment tiếng Việt ngay phía trên giải thích ý nghĩa của từng dòng code.
4. Thực hiện bài tập: Bắt UserNotFoundError và log email đã tìm.
