# Bài 01 — Python đầu tiên & cấu trúc project

Đây là bộ file độc lập của riêng bài học này. Hãy chỉnh code trong folder này và giữ nguyên folder của các bài trước để có thể mở lại, chạy lại và so sánh.

## Mục đích

Có một điểm bắt đầu sạch, chạy được và không phụ thuộc vào bất kỳ bài học nào khác.

## File chính

`main.py`

## Cách sử dụng

1. Giải nén file tải từ website.
2. Mở folder `lessons/bai-01-python-first-project/` bằng trình soạn thảo code.
3. Đọc code cùng phần giải thích từng dòng trên website.
4. Thực hiện bài tập: Đổi tên khóa học và thêm một dòng in mục tiêu học của bạn.

## Quy tắc của lộ trình

Không sửa tiếp file của bài trước. Mỗi bài là một sandbox riêng để phần thay đổi luôn rõ ràng.
